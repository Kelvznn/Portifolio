# Kélvio Nhancale — Portfolio

Portfólio estático, responsivo e pronto para publicar na Vercel.

## Estrutura

- `index.html` — conteúdo e estrutura
- `style.css` — design responsivo, animações e efeitos
- `script.js` — reveal on scroll, cursor glow e menu mobile

## Publicar no GitHub + Vercel

1. Crie um novo repositório no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Na Vercel, importe o repositório.
4. Como é um site estático, não é necessário configurar um comando de build.
5. Faça o deploy.
